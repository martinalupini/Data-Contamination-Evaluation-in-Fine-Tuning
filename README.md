# Data-Contamination-Evaluation-in-Fine-Tuning

Research project focused on detecting data contamination in Large Language Models, with particular attention to the fine-tuning phase.
The work analyzes existing detection methods (N-gram overlap, embedding similarity search, influence functions, and decoding-based approaches) and proposes a novel GAN-inspired framework to estimate contamination levels. The solution is presented at a conceptual level and not implemented, outlining an adversarial architecture with synthetic rephrasing and a discriminator to predict the percentage of overlap between training and test data, enabling a more rigorous assessment of model generalization.
